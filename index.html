DNS over HTTPS

DNS Record Finder

Look up A, AAAA, CNAME, NS, TXT, SPF, TLSA and more for any domain. Queries go straight from your browser to a public resolver.

Record types
SPF is read from TXT records that start with v=spf1. TLSA is looked up at _port._protocol.domain, so most domains return nothing for it unless DANE is set up.
